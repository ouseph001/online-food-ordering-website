# 🍔 Online Food Ordering System

A responsive and user-friendly **Online Food Ordering System** developed using **HTML, CSS, and JavaScript** as a college project. This website allows users to browse food items, search for dishes, manage their shopping cart, calculate the total bill, and place demo orders.

## 📌 Project Overview

The Online Food Ordering System provides a simple and convenient way for users to explore a food menu and order their favorite dishes through a website.

The project demonstrates the fundamentals of web development, including website design, JavaScript functionality, data handling, and browser local storage.

## ✨ Features

* 🍕 **Food Menu:** Browse a variety of food items.
* 🔍 **Food Search:** Search for food items by name.
* 🗂️ **Category Filtering:** Filter food items by category.
* 🛒 **Shopping Cart:** Add and remove food items.
* ➕ **Quantity Management:** Increase or decrease item quantities.
* 💰 **Automatic Bill Calculation:** Calculate the total cost of selected items.
* 📦 **Order Placement:** Place demo orders through the website.
* 📋 **Order History:** View previously placed orders.
* 💾 **Local Storage:** Save cart and order history in the browser.
* 📱 **Responsive Design:** Access the website on desktop and mobile devices.

## 🛠️ Technologies Used

| Technology            | Purpose                                         |
| --------------------- | ----------------------------------------------- |
| HTML5                 | Structures the website                          |
| CSS3                  | Provides styling and responsive layouts         |
| JavaScript            | Handles interactions and ordering functionality |

## 🚀 How to Run the Project

Follow these steps to run the website on your computer.

1. **Clone the repository:**

   ```bash
   git clone https://github.com/YOUR-USERNAME/online-food-ordering-system.git
   ```

2. **Open the project folder:**

   ```bash
   cd online-food-ordering-system
   ```

3. **Open the website:**

   Open `index.html` in your preferred web browser.

4. **Explore the website:**

   Browse the menu, search for food items, add items to your cart, adjust quantities, and place a demo order.

**Note:** Replace `YOUR-USERNAME` with your GitHub username before using the clone command.

## 🎯 Project Objectives

* To develop a simple and user-friendly food ordering website.
* To understand the fundamentals of HTML, CSS, and JavaScript.
* To implement search, filtering, and shopping cart functionality.
* To calculate order totals dynamically.
* To understand how browser local storage can preserve application data.
* To gain practical experience in developing a web-based application.

## 🔮 Future Enhancements

The project can be improved by adding:

* User registration and login.
* A Java backend using Spring Boot or Servlets.
* Database integration using MySQL.
* Restaurant and food management for administrators.
* Real-time order tracking.
* Secure online payment integration.

## ⚠️ Limitations

* This version is a frontend demonstration.
* Orders and cart data are stored locally in the browser.
* The website does not currently have a Java backend or database.
* Real payment processing and live order tracking are not implemented.
